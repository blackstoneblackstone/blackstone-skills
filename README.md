# Blackstone Skills

个人 Qoder / OpenClaw 技能仓库。

## 下载技能

```bash
git clone https://github.com/blackstoneblackstone/blackstone-skills.git
```

技能目录结构：
```
blackstone-skills/
├── markdown-cn-en-writing/  # 中英混排 Markdown 书写规范
├── iu-comment-scraper/      # IU 评论抓取
├── design-loop/             # AI Agent Loop 设计向导
├── wan-weigang-modern-thinking-tools-100/  # 万维钢·现代思维工具100讲
└── sql-toolkit-1.0.0/       # SQL 工具包
```

## 提交技能

1. 创建技能目录：`{skill-name}-{version}/`
2. 编写 `SKILL.md` 和 `_meta.json`
3. 提交 PR 或推送到本仓库

## 技能列表

| 技能 | 说明 |
|------|------|
| wan-weigang-modern-thinking-tools-100 | 为复杂问题选择思维工具，输出机制、权衡、行动与更新条件 |
| cosyvoice-tts | 调用阿里云 MaaS CosyVoice/Qwen TTS，将文字合成为本地音频 |
| blackstone-illustrations-1.0.0 | 为中文内容规划并生成 Blackstone 3D IP 正文配图 |
| markdown-cn-en-writing | 中英混排 Markdown 排版要点（标点、空格、标题、数字等） |
| iu-comment-scraper | 爬取 berriz.in 网站 IU 相关内容评论 |
| design-loop | 逐步设计具备独立评估、持久状态、停止条件与成本护栏的 Agent Loop |
| sql-toolkit-1.0.0 | SQL 数据库工具包（SQLite/PostgreSQL/MySQL） |
