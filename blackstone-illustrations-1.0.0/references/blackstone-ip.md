# Blackstone IP

## 固定识别特征

- 风格化 3D 成年男性人物，比例自然偏可亲，不做幼儿化大头娃娃。
- 棕色浓密短发，整齐向一侧梳起，发丝有细腻的 3D 纹理。
- 粗黑色方圆框眼镜；镜片清晰，不遮挡眼神。
- 面部干净、温和、沉稳，圆润但不过度可爱。
- 黑色圆领短袖 T 恤。
- 胸前固定有一个明亮绿色问号，这是必须保留的服装标志。
- 肤色、脸型、发型、眼镜和服装在同组图片中保持一致。

## 性格与动作

Blackstone 像一个可靠、善于思考的产品与技术工作者：专注、好奇、友好，偶尔有克制的幽默感。让他搬运、连接、拆解、筛选、修补、观察、权衡、搭建或操作场景中的核心物件。

## 可变化项

姿势、表情、手持物、道具、环境和镜头可以随主题变化。需要解释不确定性时，可以让绿色问号参与构图，但问号始终先是衣服标志。

## 禁止

- 不要默认复制参考图里的 “Thanks boss!” 对话框。
- 不要默认拿咖啡杯或闭眼微笑。
- 不要把绿色问号删除、变色、换成文字或其他符号。
- 不要改变发色、眼镜类型或黑色上衣。
- 不要生成儿童、老人、写实真人或二维线稿版本。
- 不要让人物只站在角落充当吉祥物。
- 不要添加品牌标志、水印或未经要求的文字。

## 一致性判断

若遮住胸前问号后，人物仍应凭侧梳棕发、粗黑框眼镜、脸型与黑色上衣被认出；露出问号后则应立即形成 Blackstone 的完整识别。
