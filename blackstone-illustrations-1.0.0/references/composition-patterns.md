# 构图与原创隐喻

每张只选择一种结构。

- **流程场景**：输入、Blackstone 操作、输出；适合工作流与自动化。
- **系统局部**：只呈现 3-5 个关键物件；适合来源、过滤与反馈。
- **前后对比**：左侧混乱、右侧稳定，Blackstone 完成中间的转变。
- **角色状态**：2-4 个连续动作；适合卡住、思考、行动和完成。
- **概念隐喻**：用一个大型日常物件承载抽象概念。
- **方法分层**：用台阶、抽屉、积木或架子呈现层级。
- **路线场景**：用一条清楚路径串联少量节点。
- **小型分镜**：2-4 格，每格一个动作，人物外观保持一致。

## 原创方法

1. 把抽象概念变成物理动作：连接、筛选、称量、修补、拆解、折叠、回流。
2. 选择一个可识别的日常物件：纸箱、抽屉、秤、门、梯子、管道、工作台、积木、透明容器。
3. 让 Blackstone 亲自完成决定性动作，而不是指着一个现成图表。
4. 删除不能强化核心意思的物件、箭头和文字。

不要照搬参考图的咖啡杯、闭眼表情或对话框。参考图只锁定人物身份，不锁定构图。
