# Daily US Stock Video Checklist

Treat every unchecked item as render-blocking.

## 1. Watermark and privacy gate

- [ ] Inspect opening, every transition, every source-derived still, and the final frame at full resolution.
- [ ] No `NaNa`, `NANA`, channel logo, watermark, presenter cutout, username, avatar, account ID, notification, email, phone number, or other private information is visible.
- [ ] Search project source and asset names for `nana`, `NaNa`, and `NANA`; source-analysis files may exist outside the render graph, but no referenced render asset may contain them.
- [ ] Prefer market/stock components over source screenshots.
- [ ] Every retained screenshot is generated by Imagegen from a source reference and recorded in a provenance table with source timestamp, generated asset path, removed identifiers, and reviewer result.
- [ ] If removal is ambiguous at any sampled frame, replace the image instead of approving it.

## 2. Narration, visual, and subtitle synchronization gate

- [ ] Narration is generated scene-by-scene from locked `SCRIPT.md`.
- [ ] A user-specified voice was compatibility-tested on one scene before batch synthesis; any model fallback is recorded without changing the voice.
- [ ] For a CosyVoice custom voice, the voice prefix, model, region, and SpeechSynthesizer endpoint match; every scene uses the same configuration.
- [ ] CosyVoice custom-voice synthesis uses chunks of at most 60 characters; no full 25–40 second scene is generated in one request.
- [ ] MiniMax provider region and endpoint are recorded; an endpoint mismatch is resolved before declaring the key or voice invalid, and no secret appears in logs or artifacts.
- [ ] Every narration source file has exactly one audio stream and one channel; sample rate and codec are consistent across scenes.
- [ ] Before batch synthesis, play the first probe WAV alone for 20 seconds and confirm one audible voice.
- [ ] Use `ffprobe` duration from downloaded local audio, never API-reported duration alone.
- [ ] Total delivery narration is 300–420 seconds. If pitch-preserving retiming was used, the factor is at most 1.15× and both original and delivery audio are preserved.
- [ ] Each visual scene starts with its matching narration and ends no earlier than that narration.
- [ ] Each subtitle cue falls within its matching narration scene.
- [ ] No subtitle cue overlaps the next scene or extends beyond the final video duration.
- [ ] HyperFrames timing attributes use at least six decimal places; adjacent caption clips have a 2 ms safety gap.
- [ ] Authored narration clips also end 2 ms before the next track item to prevent decoder-rounding overlap warnings.
- [ ] Every narration-segment boundary has a documented 0.8–1.2 second pause, with no narration or subtitle inside the pause.
- [ ] Review at least: every scene start +0.5s, midpoint, final 0.5s, and both sides of every transition.
- [ ] At every review point, spoken subject, visible component/ticker, and subtitle subject agree.
- [ ] The bottom caption band contains no chart, label, footer, ticker, disclosure, or decorative element behind any displayed caption.
- [ ] Full-resolution snapshots prove captions never obscure decision-relevant content; a plain or animated background beneath captions is acceptable.
- [ ] Run `scripts/verify_sync.py VIDEO --subtitle SUBTITLES.srt --expected-scenes N --scene-manifest SCENES.json` when a manifest exists, and store the JSON output as `verification-report.json`.

## 3. Content and humor gate

- [ ] Market claims are backed by the current local data snapshot or a recorded source.
- [ ] Every named stock or ETF uses the stock component; broad-market discussion uses the market component.
- [ ] For every stock/ETF, the storyboard records source time grain (`intraday`, `multi-day`, or `daily`) and evidence from the source chart/narration/axis.
- [ ] Stock component interval, visible axis, and fetched data match the recorded source time grain.
- [ ] Humor comes from rewritten setups, reversals, metaphors, or callbacks from the reference; no long verbatim copying.
- [ ] Narration stays lightly humorous across the program with specific setups/payoffs or callbacks; factual passages do not become dry lists.
- [ ] Locked narration contains no `不是……而是……` construction or superficial punctuation/synonym variant.
- [ ] Jokes do not change prices, dates, percentages, causal claims, or risk disclosures.
- [ ] Include a visible and spoken non-investment-advice disclosure.

## 4. HyperFrames and delivery gate

- [ ] Every topic/stock/ETF boundary has one documented visual transition and exactly one synchronized SFX clip; expected count is scene count minus one unless the storyboard explains an exception.
- [ ] Each SFX has a stable unique ID, local file, measured duration, source/provenance, and authored volume.
- [ ] Transition SFX do not clip, mask boundary narration, or create unexpected silence.
- [ ] Each transition animation and SFX fits inside its documented 0.8–1.2 second pause.
- [ ] MiniMax-generated audio, when used, records provider, region, model, prompt, raw asset, and any crop or processing; full-song generation is not claimed as a dedicated SFX API.
- [ ] `hyperframes check` has zero errors across runtime, layout, motion, and contrast.
- [ ] One full-frame local background image/texture runs as a seamless deterministic animation loop for the entire program and does not restart at scene boundaries.
- [ ] Background-loop snapshots near the beginning, one middle point, one loop seam, and the ending show no jump, flash, or contrast failure.
- [ ] Snapshot every scene midpoint and inspect the contact sheet.
- [ ] Reload Studio after the final source write. Press Play and verify the timecode advances, audio is enabled, captions appear, and current console logs contain no errors.
- [ ] Close or pause every other preview/player, then play final 0:00–0:20 and confirm the page has one active media element and one audible voice.
- [ ] If doubling is reported, reproduce it at an exact timestamp and classify it as source-WAV, duplicate render input, duplicate player, or channel/playback-chain behavior before applying a fix.
- [ ] Every timed `<audio>` and caption element has a stable unique ID; repeated stock scenes use unique composition IDs.
- [ ] Final output is 1920×1080, contains a video stream and audio stream, and has no unexpected silent tail.
- [ ] Final narration-led output contains exactly one audio stream and is delivered as mono unless the brief explicitly requires spatial/stereo audio.
- [ ] Preserve project, data, narration, subtitles, provenance, verification report, and MP4.
